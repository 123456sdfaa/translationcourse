MinerU 4.0

MinerU 4.0 将文档解析、本地文档库和服务工具整合到同一个工作流中，用于文档转换、应用集成和智能体（Agent）阅读。

1

它是什么？

一句话看懂 MinerU 4.0

📄

文档解析

无论 PDF、扫描图片，还是 Word / PPT / Excel，都能把其中的文字、表格与版式提取出来，整理成易读的格式。

📚

本地文档库

支持发现文件、缓存结果、全文搜索，还能按页或按块继续阅读，并保留稳定的引用定位符。

🧰

服务工具

内置 Python SDK、V1 API、批量转换、多服务 Router 与可视化 WebUI，方便应用集成与日常使用。

🤖

智能体阅读

为 AI 智能体（Agent）提供结构化的文档阅读能力，让程序也能像人一样读文档、找信息。

2

四种解析层级

按速度与精度需求自由选择

FLASH

快速预览

用于快速预览与建立索引，速度优先，适合先浏览文档大概内容、搭建检索索引的场景。

BASIC

标准解析

基于 OCR 与模型的解析方式，适合绝大多数常规文档的文字与版式提取需求。

STANDARD

标准+ 高质量

面向更复杂的版式结构，在准确度上有更严格的要求时使用。

ADVANCED

高级解析

最高规格的解析能力，用于复杂排版、高精度要求的高端场景。

💡
通俗理解： Flash 像“快速翻页浏览”，Basic 像“认真读一遍”，Standard / Advanced 则像“逐字逐句精读并严格校对” —— 越往后，解析越精细，速度也相应更慢。
3

支持的输入格式

覆盖面广，常见文档格式几乎都支持

📄 文档与办公

PDFDOC / DOCXPPT / PPTX XLS / XLSXRTFODT / ODS / ODP

🖼️ 图片与特殊格式

图片EPUBOFD HTML / MHTMLCSV / TSV
✨
DocVortex： 内置的原生文档解析引擎，负责对文档内容进行深度解析，让后续的转换与阅读更准确、更稳定。
4

文档库与智能体阅读

把文档变成可检索、可追引的知识资源

🔎

发现与搜索

自动发现文件、缓存解析结果，并支持对内容进行全文搜索，快速定位所需信息。

📍

按页 / 按块续读

可从上次中断的页面或内容块继续阅读，配合稳定的引用定位符（citation locators），追溯来源准确可靠。

🤖

为 Agent 而生

输出结构化、可定位的阅读结果，让智能体（Agent）与程序能够高效地消费文档信息。

🛡️

引用可追溯

每次引用都有稳定的定位依据，适合对出处要求严格的写作、研究与合规场景。

5

独立的模型配置

底层引擎自由选择，不被绑定

🧩

小模型引擎

可选择 ONNX 或 Torch 作为小模型推理引擎，按部署环境灵活取舍。

👁️

视觉语言模型（VLM）

视觉语言模型（能同时理解图像与文字）可选用 llama.cpp、vLLM 或 LMDeploy 运行，兼顾性能与部署方式。

💡
通俗理解： OCR = 光学字符识别，把图片或扫描件里的文字“认出来”；VLM = 视觉语言模型，能同时“看懂图、读懂字”。MinerU 允许你为两者分别指定引擎。
6

统一的工具集

从开发者到普通用户，都有一套顺手工具

🐍

Python SDK

供开发者以代码方式调用全部能力，方便嵌入自己的应用。

🔌

V1 API

标准接口，便于与其他系统做应用集成与对接。

⚙️

批量转换

无状态批量转换，一次性成批处理大量文档，无需保存中间状态。

🛰️

Router + WebUI

多服务 Router 统一调度请求；基于 Gradio 的 WebUI 则让普通用户可视化操作。

7

MarkdownHTMLLaTeX DOCXEPUBPDF 结构化内容 内容列表 V1 / V2

9

隐私与安全

你的文档，默认只留在本地

🔒
重要说明： 文档默认不会自动上传到官方服务，解析过程在本地完成；只有当你显式配置远程解析时，才会发起远程请求。敏感文档可以放心在本地处理。
